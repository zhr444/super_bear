# 🐻 Супер Медведь

**2D-платформер про медведя, собирающего мёд и убегающего от пчёл — прямо в браузере.**

Один HTML-файл. Canvas 2D, параллакс-фон, плавная физика с coyote time и jump buffer, процедурный звук на Web Audio API, тач-управление для мобильных. Никаких зависимостей, спрайтов и внешних ассетов — всё рисуется кодом.

---

## 🎮 Возможности

- **Полноценный 2D-платформер** — бег, прыжки, гравитация, коллизии с землёй и парящими платформами.
- **Продвинутая физика прыжка:**
  - 🦘 **Coyote time** — можно прыгнуть в течение нескольких кадров после схода с платформы.
  - 🎯 **Jump buffer** — нажатие прыжка за пару кадров до приземления не теряется.
  - 📏 **Переменная высота прыжка** — отпустил клавишу раньше — прыжок ниже.
- **Squash & stretch** — медведь сплющивается при приземлении и вытягивается при прыжке.
- **Анимация ходьбы** — лапы качаются в такт движению.
- **Параллакс-фон в 4 слоя:**
  - ☀️ Солнце с радиальным свечением
  - ☁️ Облака (медленный параллакс)
  - ⛰️ Дальние холмы (два слоя с разной скоростью)
  - 🌱 Трава и текстурированная земля
- **21 банка мёда** — на земле и на парящих платформах, с плавающей анимацией и свечением.
- **6 пчёл-врагов** — патрулируют по горизонтали, машут крыльями, при столкновении отбрасывают медведя и наносят временную неуязвимость.
- **Флаг победы** — развивающееся полотнище, звезда, золотой шар на вершине.
- **Процедурный звук на Web Audio API:**
  - Прыжок (квадратная волна со скольжением)
  - Приземление (низкий синус)
  - Сбор мёда (двойной восходящий синус)
  - Удар от пчелы (пила с падением)
  - Победа (мажорное арпеджио)
  - Смерть/респавн (нисходящий синус)
- **Система частиц** — искры при прыжке, приземлении, сборе мёда, ударе и победе (70 конфетти).
- **Screen shake** — тряска камеры при ударе и респавне.
- **HUD** — счётчик собранного мёда в стильной полупрозрачной плашке.
- **Три экрана состояния:**
  - 🏠 **Start** — заголовок, инструкции, пульсирующая подсказка
  - 🎮 **Play** — сама игра
  - 🏆 **Win** — результат, особая похвала за 100% сбор мёда
- **Адаптивный канвас** — с учётом `devicePixelRatio` (до 2x), без размытия на Retina.
- **Тач-управление** — виртуальные кнопки `◀ ▶ ⤴` появляются только на сенсорных устройствах.
- **Респавн при падении** — если медведь свалился в пропасть, он возвращается в начало с неуязвимостью.
- **Фиксированный шаг симуляции** — 60 FPS через accumulator, стабильная физика при любом FPS.

## 🚀 Быстрый старт

### Вариант 1 — просто открыть

```
git clone <репозиторий>
cd super-bear
```

Открой `index.html` двойным кликом в браузере.

> ⚠️ Для корректной работы `AudioContext` звук инициализируется только после первого действия пользователя (клик / нажатие клавиши / тап). Так требует браузерная политика.

### Вариант 2 — локальный сервер (рекомендуется)

```bash
# Python 3

# или Node.js
npx serve .
```

Затем открой [http://localhost:8000](http://localhost:8000).

| `⤴` | Прыжок |

Тап по самому канвасу на стартовом экране или на экране победы также работает.

## 🎯 Цель игры

- **Собери весь мёд** — 21 банка разбросана по уровню на земле и парящих платформах.
- **Доберись до флага** — он стоит в самом конце уровня (x = 3850).
- **Избегай пчёл** — столкновение отбрасывает медведя и даёт временную неуязвимость (мигание).
- **Не падай в пропасть** — между сегментами земли есть дыры. Упадёшь — респавн в начале с неуязвимостью.

На экране победы показывается, сколько мёда собрано. Если **100%** — особая похвала «✨ ИДЕАЛЬНО! Весь мёд твой! ✨».

## 🧠 Как устроена физика

### Основные константы (в коде)

```js
const GRAVITY    = 0.7;
const ACCEL      = 0.9;
const MAX_SPEED  = 5.8;
const FRICTION   = 0.82;
const JUMP_POWER = 16.5;
const COYOTE     = 7;    // кадров после схода с платформы
const JUMP_BUF   = 8;    // кадров буфера нажатия прыжка
```

### Прыжок с coyote time и jump buffer

- **Coyote time** — если игрок сходит с платформы, у него остаётся 7 кадров (≈117 мс), чтобы всё ещё прыгнуть. Убирает ощущение «нечестной» потери прыжка.
- **Jump buffer** — если игрок нажимает прыжок за 8 кадров до приземления, нажатие запоминается и срабатывает сразу при касании земли. Убирает ощущение «проглоченного» ввода.
- **Переменная высота** — если отпустить клавишу прыжка во время подъёма (`vy < -4`), скорость подъёма умножается на 0.55. Короткое нажатие — короткий прыжок, долгое — высокий.

### Squash & stretch

При прыжке медведь растягивается `(0.82, 1.2)`, при сильном приземлении сплющивается `(1.28, 0.76)`. Значения плавно возвращаются к `(1, 1)` через `lerp`, создавая эффект «резинового» персонажа.

### Порядок разрешения коллизий

1. Движение по X → проверка пересечений → выталкивание по X.
2. Движение по Y → проверка пересечений → выталкивание по Y.
3. Если приземление с `vy > 8` → эффект squash + звук + частицы пыли.

Такой порядок (раздельные оси) — классический подход, предотвращающий застревание в углах.

## 🎨 Графика

Всё рисуется кодом через Canvas 2D:

- **Солнце** — радиальный градиент + круг.
- **Облака** — 4 перекрывающихся круга с полупрозрачной заливкой.
- **Холмы** — дуги, сдвигающиеся с параллакс-множителем.
- **Земля** — коричневая заливка + текстура из тёмных квадратов + трава из двух слоёв зелёного + травинки-треугольники.
- **Платформы** — деревянные, со скруглёнными углами (`roundRect`), бликом сверху, заклёпками и мхом.
- **Мёд** — жёлтая банка с крышкой, блик-эллипс, капля и радиальное свечение.
- **Пчёлы** — тело-эллипс, чёрные полоски, жало, глаз, машущие крылья (поворот эллипсов через `sin`).
- **Флаг** — шест, шар, полотнище из двух кривых Безье (эффект волны через `sin(time)`), звезда.
- **Медведь** — тело, живот, лапы, уши, голова, морда, нос, рот, глаза с бликами. Лапы и руки качаются через `sin(walkPhase)`.

Ни одного изображения, спрайта или SVG-файла.

## 🔊 Звук

Все эффекты генерируются через `OscillatorNode` + `GainNode`:

| Событие | Форма волны | Частота | Слайд |
|---------|-------------|---------|-------|
| Прыжок | square | 320 Hz | +220 Hz |
| Приземление | sine | 120 Hz | −40 Hz |
| Сбор мёда | sine | 880 Hz → 1320 Hz | двойной |
| Удар пчелы | sawtooth | 160 Hz | −80 Hz |
| Респавн | sine | 200 Hz | −120 Hz |
| Победа | sine | 660 → 880 → 1100 Hz | арпеджио |

`AudioContext` создаётся лениво при первом действии пользователя — так требует браузерная политика автовоспроизведения.

## 🐛 Известные особенности

- Звук инициализируется только после первого действия пользователя — так требует браузер.
- На экранах с `devicePixelRatio > 2` канвас ограничивается в 2x для производительности.
- При потере фокуса вкладки `requestAnimationFrame` приостанавливается — игра ставится на паузу (неявно).
- Тач-кнопки появляются только если браузер сообщает о наличии сенсорного ввода (`ontouchstart` или `maxTouchPoints > 0`).
